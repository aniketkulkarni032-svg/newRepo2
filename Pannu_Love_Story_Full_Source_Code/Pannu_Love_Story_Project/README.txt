Pannu's Love Story — Website Project

Files:
- index.html: complete website HTML, CSS, and JavaScript
- assets/photo1.jpg ... photo6.jpg: your six original uploaded photos

How to run:
1. Keep index.html and the assets folder together.
2. Double-click index.html to open it in a browser.
3. To publish on Netlify Drop, upload the whole project folder (or the ZIP).

To edit:
- Change text in index.html.
- Change colours in the :root CSS variables.
- Replace photos in assets, keeping the same filenames if you want to avoid editing HTML.
